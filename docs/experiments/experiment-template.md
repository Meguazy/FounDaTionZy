# EXP-NNN: Question or hypothesis

- Outcome: not run
- Date / run ID: unset
- Owner: unset
- Related requirement / OD / ADR / step: unset
- Hypothesis and pass/fail criterion: unset
- Source revision / configuration / fixture identity: unset
- Environment / versions / actual dependencies: unset
- Account, cost, permission, and fixture authorization: unset

## Procedure

Describe reproducible inputs, commands actually available, expected observations,
time/resource bounds, safe fixtures, and cleanup. Mark planned commands as
planned. Never include credentials, sessions, or private owner data.

## Results

Record actual commands, outcome/counts, failures/skips, sanitized evidence, and
cleanup. Distinguish failed, inconclusive, unsupported, and not run.

## Interpretation and limits

Explain what the observations support and what they do not prove. Retain
unexpected results and contradictory evidence.

## Decision and follow-up

Link the owner's decision/promotion, ADR/OD changes, roadmap consequences,
remaining questions, and any new authorized run scope. Preparation is not proof
that the experiment ran.

# Probe code

Place optional project probes in `experiments/EXP-NNN/`, with reusable probe
helpers in `experiments/shared/`. Index their design/results under
[docs/experiments](../docs/experiments/README.md).

No probe or application code is supplied by this template. Application modules
must not import this tree. If a proven approach is promoted, implement the
production boundary deliberately with its own contracts, tests, configuration,
and operational documentation.
